## The prompt

```text
Edit podcast-ep12.mp4 for YouTube (16:9):
- remove silences longer than 0.6s, keep natural pauses
- add chapter title cards for each topic
- add lower-third name tags for both speakers
- add English subtitles as a separate .srt file
Then find the 3 best 30–60 second moments and make them 9:16 Shorts with captions.
Show me the plan first.
```

## Good to know

- Long videos take longer to render. Keep your computer awake and plugged in.
- Ask for a **plan first** so you can check the cuts before rendering the full video.
- For very long recordings, ask the agent to work **one chapter at a time**. This uses less of your AI plan's limits.
